# Atlas V2

Static HTML, CSS and JavaScript; deploy main branch root with GitHub Pages.

- graph.js: typed nodes, explicit relationship labels, platform hosting edges. Illustrative data only.
- app.js: one-hop neighborhood with contextual two-hop destinations and projects; semantic depth layout; interruptible 400 ms cubic movement from current positions.
- style.css: distant platforms/projects, middle actors/activities, foreground channels/results, elliptical planes, depth shading and scaling. This is a 2.5D spatial representation, not a rotatable 3D scene.

Validation: Chrome interaction through project -> named agent -> channel; platform -> threads and projects; back/home and mode changes. Responsive layout inspected in 390 px and 820 px iframe viewports. Physical Safari devices and native touch performance remain unverified. Automatic AI ingestion is not implemented.


V3 visual refinement: CSS orbital rings, SVG decorative connection pulses, 18 faint CSS stars, a perspective grid and pointer tap echoes. No imagery, libraries, API calls or live-status claims. Reduced-motion disables ambient animations. Graph topology and navigation remain unchanged.
